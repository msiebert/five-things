  - id: "2026-08-02-1"
    question: "What was the name of the first web browser, which doubled as a page editor?"
    answer: "WorldWideWeb"
    topic: technology
    explanation: >-
      Tim Berners-Lee's original browser, named WorldWideWeb (and later
      renamed Nexus to avoid confusion with the Web itself), let users edit
      pages directly in the same window they browsed them in, much like a
      word processor. Berners-Lee's original vision was a fully two-way
      medium, where reading and writing the Web were equally easy for
      everyone. That editing capability was dropped from the browsers that
      followed, which focused on fast rendering instead, and the read/write
      Web he originally imagined didn't really return in a mainstream form
      until wikis and blogging platforms arrived more than a decade later.
  - id: "2026-08-02-2"
    question: "What was the only HTTP method supported by the original HTTP/0.9 protocol?"
    answer: "GET"
    topic: technology
    explanation: >-
      The version of HTTP that shipped with the Web in 1991 was strikingly
      minimal: a client would open a connection, send a single line like
      "GET /page.html", and the server would respond with raw HTML and then
      close the connection — no headers, no status codes, no way to request
      anything other than HTML. Features taken for granted today, like
      specifying a file's content type, caching instructions, or even a
      numeric response code such as 404, weren't added until HTTP/1.0 was
      formalized a few years later as the Web's needs grew far beyond CERN's
      original use case.
  - id: "2026-08-02-3"
    question: "What 1993 browser is usually credited with driving the Web's first mass adoption, years after it was invented?"
    answer: "Mosaic"
    topic: technology
    explanation: >-
      The Web existed for roughly two years as a niche tool used mostly by
      physicists and academics before Mosaic, released by NCSA in 1993, made
      it broadly popular. Mosaic's key innovation was displaying images
      inline with text on the same page, instead of as separate downloadable
      files — a visual, magazine-like experience earlier text-only browsers
      couldn't offer. Its lead developer, Marc Andreessen, went on to found
      Netscape, whose browser dominated the mid-1990s Web and helped trigger
      the dot-com boom.
  - id: "2026-08-02-4"
    question: "What computer brand ran the entire World Wide Web in its first months?"
    answer: "NeXT"
    topic: technology
    explanation: >-
      In the Web's first months, the entire World Wide Web ran on a single
      NeXT computer sitting on Berners-Lee's desk at CERN — if that machine
      were switched off, the Web would go down with it. He taped a
      handwritten note to it warning colleagues, "This machine is a server.
      DO NOT POWER IT DOWN!!", a strikingly fragile setup for what would
      become global infrastructure. That original NeXT cube is preserved at
      CERN today, and the sticker is a well-known artifact among Web
      historians.
  - id: "2026-08-02-5"
    question: "Who coined the term \"hypertext,\" the concept the Web was built on, decades before it existed?"
    answer: "Ted Nelson"
    topic: technology
    explanation: >-
      The idea of linked, non-linear text predates the Web by more than two
      decades: computer scientist Ted Nelson coined "hypertext" in 1965 to
      describe writing that branches and lets readers choose their own path
      through it, as part of his lifelong (and never fully realized) Xanadu
      project. Berners-Lee's breakthrough wasn't inventing hypertext, but
      combining that existing idea with the internet's networking protocols
      so links could point to documents on any computer, anywhere, rather
      than just within a single system.
