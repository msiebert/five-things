Today's topic: The World Wide Web (technology)

Who invented the World Wide Web, and where?

Tim Berners-Lee, at CERN

Tim Berners-Lee, a British computer scientist working at CERN, the European particle physics laboratory near Geneva, created the World Wide Web to make it easier for researchers to share and link information across different computers. Before the Web, CERN's scientists had no simple way to follow references between documents stored on separate systems. Berners-Lee's solution combined hypertext with the internet's existing networking infrastructure, and CERN later made the invention available to everyone at no cost, which was key to its explosive global growth in the 1990s.

In what year did Tim Berners-Lee submit his original proposal for the World Wide Web?

1989

In March 1989, Berners-Lee circulated a document at CERN titled "Information Management: A Proposal," outlining a system for linking and accessing information across a distributed network. His manager, Mike Sendall, famously annotated it "vague but exciting," and gave him time to pursue it. Berners-Lee spent the next two years building the first web browser, web server, and the core web technologies before the Web became usable outside CERN.

What was the address of the first website ever published?

info.cern.ch

The first website, published in 1991, ran on Berners-Lee's own NeXT computer at CERN and explained what the World Wide Web was, how to use a browser, and how to set up a web server. The original site was taken offline for years before CERN restored a copy in 2013 as part of an effort to preserve early Web history, and info.cern.ch remains reachable today as a historical landmark of the internet.

What three core technologies did Berners-Lee combine to create the Web?

HTML, URLs, and HTTP

HTML (HyperText Markup Language) gave documents a way to be formatted and linked to one another; the URL (Uniform Resource Locator) gave every page a unique address; and HTTP (HyperText Transfer Protocol) defined how browsers and servers would exchange those documents over the internet. Together, these three pieces formed the minimal toolkit needed to publish and retrieve linked documents at scale, and all three remain foundational to the Web more than three decades later.

In what year did CERN place the World Wide Web technology in the public domain, royalty-free?

1993

In April 1993, CERN announced that the World Wide Web's underlying software would be free for anyone to use and build upon, with no royalties owed. This decision, rather than licensing the technology, is widely credited as a turning point that let the Web spread rapidly across universities, businesses, and eventually the public, instead of remaining a niche tool restricted by licensing fees or competing proprietary standards.
