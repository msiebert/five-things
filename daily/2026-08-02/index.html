Today's topic: The World Wide Web (technology)

What was unusual about the very first web browser, compared to browsers today?

It was also a page editor (WYSIWYG), not just a viewer

Tim Berners-Lee's original browser, called WorldWideWeb (and later renamed Nexus to avoid confusion with the Web itself), let users edit pages directly in the same window they browsed them in, much like a word processor. Berners-Lee's original vision was a fully two-way medium, where reading and writing the Web were equally easy for everyone. That editing capability was dropped from the browsers that followed, which focused on fast rendering instead, and the read/write Web he originally imagined didn't really return in a mainstream form until wikis and blogging platforms arrived more than a decade later.

How many commands did the original HTTP protocol (HTTP/0.9) support?

One — GET, with no headers or status codes

The version of HTTP that shipped with the Web in 1991 was strikingly minimal: a client would open a connection, send a single line like "GET /page.html", and the server would respond with raw HTML and then close the connection — no headers, no status codes, no way to request anything other than HTML. Features taken for granted today, like specifying a file's content type, caching instructions, or even a numeric response code such as 404, weren't added until HTTP/1.0 was formalized a few years later as the Web's needs grew far beyond CERN's original use case.

What 1993 browser is usually credited with driving the Web's first mass adoption, years after it was invented?

Mosaic

The Web existed for roughly two years as a niche tool used mostly by physicists and academics before Mosaic, released by NCSA in 1993, made it broadly popular. Mosaic's key innovation was displaying images inline with text on the same page, instead of as separate downloadable files — a visual, magazine-like experience earlier text-only browsers couldn't offer. Its lead developer, Marc Andreessen, went on to found Netscape, whose browser dominated the mid-1990s Web and helped trigger the dot-com boom.

What warning did Tim Berners-Lee tape to the computer that ran the entire early Web?

"This machine is a server. DO NOT POWER IT DOWN!!"

In the Web's first months, the entire World Wide Web ran on a single NeXT computer sitting on Berners-Lee's desk at CERN — if that machine were switched off, the Web would go down with it. He taped a handwritten note to it warning colleagues not to turn it off, a strikingly fragile setup for what would become global infrastructure. That original NeXT cube is preserved at CERN today, and a replica of the sticker is a well-known artifact among Web historians.

Who coined the term "hypertext," the concept the Web was built on, and decades before it existed?

Ted Nelson, in 1965

The idea of linked, non-linear text predates the Web by more than two decades: computer scientist Ted Nelson coined "hypertext" in 1965 to describe writing that branches and lets readers choose their own path through it, as part of his lifelong (and never fully realized) Xanadu project. Berners-Lee's breakthrough wasn't inventing hypertext, but combining that existing idea with the internet's networking protocols so links could point to documents on any computer, anywhere, rather than just within a single system.
